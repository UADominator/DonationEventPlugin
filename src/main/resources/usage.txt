                                    Як використовувати плагін?

1. Додайте ключ в config.yml (V1.0 Підтримка тільки Donatello)
2. За бажанням змініть events.json
3. Насолоджуйтесь.

Команди:
/OpenSettingsMenu - відкриває меню із івентами. Тут ви знайдете всі доступні івенти, при виборі одного із них відкриєтсья редагування його.
                    Лівий блок - стартова сума, правий блок - кінцева сума за якої може спрацювати донат.
                    Скло посередині вимикає івент (встановлює обидві суми на 0)

/SetEpiKey - встановлює "АПІ" ключ за яким будуть отримуватись донати. Переваги: ключ зберігаєтсья в оперативній пам'ятті серверу, звідки його
             майже неможливо дістати. Але будьте уважні при наступному перезапуску серверу він скинеться
             Використання: /setApiKey fsfsdff1as65df43sdv165g4dsa2v1 1
             1 - Dyaka (НЕ підтримуєтсья)
             2 - Donatello
             3 - Mono (НЕ підтримуєтсья)

/RandEventSum - викликає випадковий івент із заданою сумою або сумою 1.
                  Використання: /RandEventSum 69.5 (викличе випадковий із івентів із сумою 69.5)



                                    Як додавати свій івент?

1. Відкрийте файлик events.json
2. В блоці eventsArrays в [] через кому задаються івенти в {}:
                                                                                                    нижче наведений тільки приклад. Json формат не підримує жодні коментарі такі як //.
                                                                                                    Тому не копіюйте ці коментарі в файл, у вас просто не буде нічого працювати 0_o.
    {
      "events": {
        "eventName": "Броньований Зомбі",                                                           //Це просто назва, для зручності пошуку івенту в меню
        "icon": "minecraft:iron_chestplate",                                                        //Іконка яка буде відображатися в меню
        "price": {
          "startSum": 10,                                                                           //Початкова сума від якої може спрацювати івент
          "endSum": 50                                                                              //Кінцева сума від якої може спрацювати івент
        },
        "commands": [                                                                               //Це перелік команд які викличуться в цьому івенті. Їх може бути необмежена к-ть.
          {
            "type": "STRING_CORDS_STRING",                                                          //Це задання типу за для розпізнавання, в цюму випадку: команда, координати гравця, друга частина - до прикладу нбт теги.
            "command": "summon zombie %d %d %d %s",                                                 //Сама команда, %d - координати. %s - обов'язкове до введення(друга частина команди)
            "addition": "{\"CustomName\":\"\\\"Броньований Зомбі\\\"\"}"                            //Друга частина команди, те що вставляєтсья замість %s
          },                                                                                        //(Обов'язково якщо є символи %, /, \, ". перед ними додавати \ для розпізнавання, інакше воно не буде рпацювати)
          {
            "type": "STRING_PLAYER_STRING",                                                         //Тип: команда, гравець, друга частина
            "command": "execute as %s at @p run %s",
            "addition": "fill ~-1 ~3 ~-1 ~1 ~5 ~1 minecraft:lava"
          },
          {
            "type": "STRING_PLAYER_CORDS_STRING",                                                   //Тип: команда, гравець, три координати гравця, друга частина
            "command": "tp %s %d %d %d %s",                                                         //Тут в мене не було ідей для прикладу але я вірю що ви знайдете використання для цього <3.
            "addition": ""
          },
          {
            "type": "CUSTOM_EVENT",                                                                 //Тип: унікальний. Тут вже визначено автором що буде виконуватися залежно від того яку ви введети першу частину.
            "command": "inventoryShake",                                                            //Перемішає інвентар гравця.
            "addition": ""
         },
        ]
      }
    }


                                    Доступні кастомні івенти:

"inventoryShake" - Перемішує інвентар гравця                                                        //V1.0
